# Snake (vanilla JS)

A simple, modern-looking Snake game built with HTML5 Canvas and plain JavaScript.

## Run

- Open `index.html` in any modern browser.
- Controls:
  - Arrow keys or WASD to move
  - P to pause/resume
  - R to restart
- Use the speed dropdown to change difficulty.

## Files

- `index.html`: markup and UI controls
- `styles.css`: minimal styling with light/dark support
- `main.js`: game logic and rendering
